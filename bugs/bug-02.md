# BUG-02: Буруу JSON хүсэлтэд HTTP 200 OK буцааж байна

**Орчин:** Уншлагын жагсаалт v2.0, Windows 11, 2026-10-19

**Ноцтой байдал:** Major — API буруу JSON хүсэлтийг амжилттай гэж мэдээлж байна.

**Олдсон аялал:** Saboteur Tour — API-д буруу бүтэцтэй JSON илгээж, HTTP статус болон серверийн хариуг шалгах.

**Илрүүлсэн цаг:** 20:42 (сессийн 16:32 дахь тэмдэглэл)

## Урьдчилсан нөхцөл

`node app.js` командаар серверийг ажиллуулсан байна.

## Дахин гаргах алхам

1. API-д буруу бүтэцтэй JSON хүсэлт илгээнэ.
2. Серверээс ирсэн HTTP статусыг шалгана.
3. Хариуны JSON өгөгдлийг шалгана.

## Хүлээгдэж байсан үр дүн

Сервер буруу JSON хүсэлтэд `400 Bad Request` буцааж, алдааны мэдээлэл өгөх ёстой.

## Бодит үр дүн

Сервер `HTTP/1.1 200 OK` статус болон `{"result":"OK"}` хариу буцаасан.
